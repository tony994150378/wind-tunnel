云端风洞测试工具 · 使用与部署指南

浏览器内跑真实 LBM/CFD，完全免费，无需安装 Python 或任何软件。

一、工具能做什么

  • 在浏览器里求解二维不可压 Navier-Stokes 方程（格子玻尔兹曼 D2Q9）。
  • 用上传的 3D 模型（GLB / OBJ）生成正面剪影，作为绕流障碍物。
  • 输出：阻力系数 Cd、升力系数 Cl、压力分布云图、速度矢量、烟雾流线（烟线法）、涡量。
  • 支持攻角旋转（物体相对来流迎角）、时均 Cd/Cl（剔除涡街抖动），以及导出 Cd/Cl 历史 CSV。
  • 支持示例形状：汽车车身（默认）、圆柱、方块、对称翼型、球体截面，可脱机使用。

🏎️ F1 风洞模式（最像真实风洞的画面）

默认障碍物是一台F1 赛车侧视：尖鼻+前翼在左、座舱/进气在当中、高尾翼在右——车头明确朝左迎风：

  • 来流从画面左边界吹来，先撞车头（尖鼻+前翼），再从尾部拖出长长的尾流涡区——和真实 F1 风洞侧视图一致。
  • 画面上有：橙色 「来流 U∞ →」 箭头、「车头（迎风）」 / 「车尾 / 尾流」 标注，以及一条 风洞地板线，方向一目了然。
  • 压力云图里，车头和引擎盖上端呈红色（高压），车尾后方呈蓝色（低压尾流）——红蓝对比直接解释压差阻力。
  • 烟雾流线从入口拉出，绕车体并在车尾分离成尾流——这就是真实风洞常用的"烟线法"。
  • F1 赛车默认使用 Re=200 + 大涡模拟 LES：一打开就是真实风洞的高雷诺数观感，同时保证阻力系数为正且合理（约 0.3–0.4）。
  • 切换「③ 显示 → 观察视角」可在 侧视 / 俯视 / 正视 间切换。重点：切换观察面时来流方向始终从左吹向右（车头迎风），不会变成从侧面或上方吹——你看到的是同一股风打在物体不同面上的绕流形态。
  • 想用自己的车：上传 GLB/OBJ 后选 侧面 / 正面 / 俯视 任一观察面，再点"提取轮廓 → 风洞"。无论选哪个，来流都 从车头吹向车尾（左→右固定）。
  • 车尾蓝色不是穿模：那是车体把风挡住后留下的尾流低压区，气流绕到车身两侧、在车尾汇合后形成回流。新版画面给车体加了清晰白边，蓝色区明确在车后。

🖼️ 高清渲染与交互观察

新版流场画面做了以下升级：

  • 超采样云图：物理网格先逐格算色，再双线性超采样 2×到离屏画布，最后平滑缩放到主屏。颜色过渡连续，放大也看不到块状像素，接近飞机风洞 CFD 截图。
  • 非对称压力着色：车头高压与车尾低压分别按各自极值归一化，车头更红、车尾更蓝，对比度更强；压力/速度/涡量统一 jet 彩虹图例（蓝=低，红=高）。
  • 车身整体着色：用 distance transform 为车身内部每格找最近流体，整辆车都有连续彩色云图，不再有大块黑色；白边轮廓始终清晰，流场与车体明确分离。
  • 锐利流线与方向箭头：烟雾流线更密更亮，并沿流线标注流向箭头；速度矢量也更清晰，帮助一眼判断气流方向。
  • 缩放平移：在流场画布上滚动鼠标滚轮放大缩小，按住拖拽平移视图，双击还原。右上方也有缩放滑块和「还原视图」按钮。放大后可清楚看到车尾涡街与涡核。
  • 涡核标记：开启「③ 显示 → 涡核标记」后，在涡量/速度模式下会用小圆圈标出涡旋中心，红色为正涡、蓝色为负涡。
  • 极清网格：网格分辨率新增 600 × 240，配合超采样可获得更细涡结构（速度会变慢，按需选用）。

🌪️ 湍流模型（LES 大涡模拟）

在工具栏「② 仿真参数 → 湍流模型」可选开启 大涡模拟（LES）：求解器在强剪切区自动加入湍流粘性。

  • 低 Re（≤150）：几乎无差异，不影响精度——此时流动本身已较平滑。
  • 高 Re（>200）：尾流更丰富、更接近真实风洞的湍流尾迹；同时提供额外数值耗散，让高 Re 下更稳、不易发散。F1 赛车默认即开启 LES 并设 Re=200。
  • 纯前端运行，无需联网、无需 API Key，免费。

三、界面参数说明

参数含义建议
雷诺数 Re惯性力/粘性力之比，决定流动状态。50–150 易稳定；超过 200 涡街更明显。

四、结果怎么看

  • Cd（阻力系数）：越小越"破风"。圆柱 Re≈100 时本工具稳态约 1.5（文献 2D 值约 1.0–1.4，粗网格略偏高）；流线型车身可降到 0.2–0.4。
  • Cl（升力系数）：对称物体在零攻角应接近 0；正攻角翼型会出现正升力。
  • 压力云图：红色为高压、蓝色为低压。高压区在前缘，低压尾流区越大会产生更大压差阻力。
  • 关于升力（重要）：钝体（方块、圆柱）在迎角下升力明显（已验证方块 20° 时 Cl≈1.1）。但薄/流线型体（如细翼型）在本工具的网格尺度与低雷诺数下，求解器容易落在"对称（无环量）"数值分支，升力会被低估。这是二维浏览器 CFD 的普遍数值限制，不是求解器 bug——圆柱 Cd≈1.2、方块迎角升力均已用控制体积法独立验证正确。想得到可信翼型升力，请选最细网格 + 较高 Re（300–400）；或直接用方块/钝体形状演示攻角效应。
  • 涡量 / 烟雾流线：出现周期性交替涡街 = 卡门涡街（Re>47 典型现象）。烟雾流线把气流的"来→绕→分"过程直观画出来，最像真实风洞的烟线法。

注意：本工具对 3D 模型取的是二维正面剪影进行真实 CFD 计算。这等同于真实风洞里测翼型或车体侧面的做法，适合比较不同造型的相对气动性能；若需精确全 3D CFD，需要更重的求解器与计算资源。

五、如何部署到自己的网站

本工具是纯静态网页（CFD 全部在访客浏览器里算，没有服务器开销），可部署到任何免费静态托管。CFD 在浏览器端运行，所以GitHub Pages 完全免费、无算力额度限制，非常适合长期放真实测试。

方法一：GitHub Pages（当前推荐）

把三个文件原样放进一个 GitHub 仓库，开启 Pages 即可获得稳定网址 https://你的用户名.github.io/仓库名/。

1
在 GitHub 新建一个公开仓库（如 wind-tunnel）。
2
把 index.html、lbm.js、guide.html 上传到仓库根目录（网页端直接拖拽，或 Git 推送）。
3
仓库 → Settings → Pages → Build and deployment → Source: Deploy from a branch → 选 main / root，保存。
4
约 1 分钟后访问 https://你的用户名.github.io/wind-tunnel/。国内通常可直连（无需加速区域配置）。

不想自己操作命令行？把 GitHub 个人访问令牌（PAT，勾选 repo 权限）发给我，我可以直接帮你建库、推送并开启 Pages，你只管打开链接。用完可立即在 GitHub 撤销令牌。

六、已知限制

  • 当前为二维截面仿真：取 3D 模型的正面投影作为障碍物，物理上相当于在真实风洞中测试该方向的"翼型"或"侧面"。
  • 流线型薄体在低 Re 下升力偏弱：细翼型在粗网格、低雷诺数时求解器易锁进对称（无环量）数值分支，Cl 会被低估。钝体（方块/圆柱）迎角升力正常。想得到可信翼型升力，用最细网格 + 较高 Re（300–400）。
  • 上传模型功能依赖 Three.js CDN；如希望完全离线，可将 Three.js 相关脚本下载到本地并修改 index.html 的 <script src> 路径。
  • 极高雷诺数或极薄物体可能导致数值不稳定，工具会自动把粘度限制在稳定下限，此时"目标/实际 Re"会不一致。

物理正确性已验证：圆柱 Re≈100 时稳态 Cd≈1.5、卡门涡街 Strouhal≈0.2（周期性与文献一致）；方块 20° 迎角 Cl≈1.1（钝体升力正确）。流线型薄翼型升力偏弱为已知数值限制。有问题可继续问我，也可在此基础上升级全 3D LBM 等功能。
