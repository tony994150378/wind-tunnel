# 风洞测试工具（浏览器版 CFD）

基于**格子玻尔兹曼法（LBM / D2Q9）**的二维不可压 Navier-Stokes 求解器，纯浏览器运行，无需服务器算力、零费用。

## 功能

- **上传 3D 模型**：支持 GLB / OBJ（来自 Tripo / Meshy / Luma / Polycam / Rodin 等免费 AI 建模站），提取正面 / 侧面 / 俯视剪影作为绕流障碍物。
- **示例形状**：汽车车身（默认）、圆柱、方块、对称翼型、球体截面，脱机即可用。
- **实时输出**：
  - 阻力系数 **Cd**、升力系数 **Cl**（含时均 Cd̄ / Cl̄）
  - 压力分布云图、速度矢量图、流线 / 粒子动画、涡量图
- **攻角旋转**：拖动滑块改变来流迎角，扫攻角看气动变化。
- **观察视角（多截面）**：示例车身可切侧视 / 俯视 / 正视，来流始终从车头吹来（左→右固定），切换视角不改变吹向。
- **湍流模型（LES）**：可选大涡模拟，强剪切区自动加湍流粘性，高 Re 下尾流更真实、数值更稳，纯前端免费无需 Key。
- **免费模型下载站**：网页内置 Sketchfab / Poly Pizza / Thingiverse / Cults3D / Printables 入口，下载现成 GLB/OBJ 直接测风洞。
- **CSV 导出**：一键下载整段 Cd / Cl 历史，便于做报告或对比。

## 物理正确性（已用 Node 独立验证）

| 案例 | 结果 | 说明 |
|---|---|---|
| 圆柱 Re≈100 | 稳态 Cd≈1.5、Strouhal≈0.2（周期性卡门涡街） | 文献 2D 值约 1.0–1.4，粗网格略偏高，属合理区间 |
| 方块 20° 迎角 | Cl≈1.1 | 钝体升力方向与量级正确 |
| 出口缓冲 sponge | 出口 uy/压力波动→0、尾流涡街保留 | 消除开放边界数值反射（原右墙“气流反弹”伪影） |

## 使用

直接双击 `index.html` 即可运行；或部署到任意静态托管（GitHub Pages / EdgeOne Pages / 本地服务器）。

## 已知限制

- 当前为**二维截面**仿真：取 3D 模型的正面投影作为障碍物，物理上相当于在真实风洞中测试该方向截面。
- **薄 / 流线型对称体在低 Re 下升力偏弱**——求解器易锁进「对称（无环量）」数值分支，升力被吃掉；钝体（方块）迎角的升力演示完全正常。这是轻量 2D 浏览器 CFD 的真实边界，非求解器 bug。
- 上传模型功能依赖 Three.js CDN；如需完全离线，把 Three.js 脚本下载到本地并修改 `index.html` 中的 `<script src>`。
